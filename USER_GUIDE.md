# S-TEMS User Guide

**Springer Talent Enablement Management System**

Welcome to S-TEMS! This guide helps you navigate the application based on your role.

---

## Getting Started

1. Open **http://localhost:5173** in your browser
2. Enter your **email** and **password**
3. You'll be redirected to your role's dashboard automatically

---

## System Admin

### Dashboard
View system overview and user statistics.

### Add Users
Create new user accounts:
- Fill in Username, Email, Password
- Select a **Role** (TA Manager, TA Head, Hiring Manager, etc.)
- Select a **Department** (Data & Analytics, Product Engineering, etc.)
- Click **Create User**

### Manage Users
View, search, and manage all registered users in the system.

---

## TA Manager (Talent Acquisition Manager)

### Dashboard
View the **Drive Dashboard** with:
- Candidate funnel visualization (Applied → Joined)
- Cycle-wise statistics (Total, Selected, Accepted, Rejected, Dropped, Joined)
- Drive counts (On-Campus / Off-Campus)

### Hiring Cycles
View and manage hiring cycles:
- Each cycle has a **Year**, **Budget**, **Compensation Band**, and **Status** (OPEN/CLOSED)
- Click on a cycle to see its demands and details
- Use the **Global Filter** to filter by cycle year

### Hiring Calendar
Visual calendar showing all scheduled drives and events.

### Institutes
Manage partner institutions:
- View institute list with TPO contacts
- Add new institutes (name, location, TPO details, tier)
- View institute analytics (candidates, conversion rates)

### Candidates
Browse and filter all candidates:
- **Pagination**: 20 candidates per page (handles 1,500+ efficiently)
- **Filters**: Name, Institute, State, Degree, Department, Skills, Application Stage, Eligibility
- Click a candidate to view full details, history, and documents

### Drive Dashboard
Manage recruitment drives:
1. Select a **Hiring Cycle**
2. View drives in that cycle
3. Click a drive to see candidates, rounds, and panel allocations
4. Allocate panels and record interview scores

### Document Processing
Three tabs for managing candidate documents:

**📤 Send Documents** — Request documents from candidates
- Select candidates and document types to request
- Track which candidates have submitted documents (✓ submitted, ○ pending)

**📋 Review & Verify** — Review uploaded documents
- View document counts (Awaiting, Approved, Rejected)
- Open each document, verify/reject with comments
- Bulk actions available

**📨 Offer Responses** — Track offer acceptance
- View candidates with all documents approved
- Monitor offer status (Pending, Accepted, Declined)

### Academy
View and manage the training academy:
- **Attendance** — Mark daily attendance (manual or Excel upload)
- **Scores** — Record course-wise scores for interns
- **Intern Progress** — Monitor trainee performance and readiness

### Settings (Manage)
Configure system-wide settings:
- **Skills** — Manage skill categories for scoring
- **Eligibility Rules** — Define eligibility criteria for candidates
- **Round Templates** — Create interview round templates
- **Email Templates** — Manage automated email templates

## TA Head (Talent Acquisition Head)

### Dashboard
Same Drive Dashboard as TA Manager — view hiring funnel and statistics.

### Hiring Cycles
View and **edit** hiring cycles:
- Update Budget (₹), Compensation Band, Status
- Approve or close cycles
- View demands under each cycle

### Hiring Calendar
View all scheduled drives and recruitment events.

### Academy
Full read/write access to the Academy dashboard — same features as TA Manager.

### Settings (Request)
Manage configuration settings (Skills, Eligibility, Rounds, Email Templates).

## Training Coordinator

### Dashboard
Training-specific overview:
- **Active Students** count (currently enrolled)
- **Average Attendance** percentage
- **Scores Recorded** summary
- **Students At Risk** (attendance below 75%)
- **Project Ready** count

### Academy
Full training management:

**Attendance Tab**
- Select Year → Program → Batch
- View student attendance list with percentages
- Mark attendance: Present ✅ / Absent ❌ / Leave
- Upload attendance via **Excel** (download template first)

**Scores Tab**
- Select a course
- Enter scores for each student
- Classification auto-calculates (Excellent / Good / Need Learning)

**Intern Progress Tab**
- View each intern's training journey
- Track milestones and completion status
- Mark readiness for projects

## Panel Members

### Dashboard
Drive Dashboard — view recruitment statistics for cycles you're assigned to.

### Panel Assignments
View drives and rounds where you're assigned as a panel member. See candidate lists for upcoming interviews.

### Panel History
View history of all panel assignments and scoring you've completed.

### Academy Scoreboard
**Read-only** view of the academy dashboard — monitor intern attendance and scores.

## Intern

### Dashboard
Your personal training overview:
- **Program name**, Batch number, Year
- **Attendance** percentage
- **Batch Rank** (e.g., "4th out of 28")
- **Courses Scored** count
- Quick-access cards to all pages

### My Scores
View your course scores and see where you stand on the batch leaderboard.

### My Progress
Track your training journey — milestones completed, current status, and upcoming goals.

### Calendar
View your training schedule, events, and attendance history on a calendar view.

### Certificates
Upload and manage your training completion certificates. Supported formats: PDF, images.

### My Profile
View and edit your profile:
- Bio text
- Profile links (LinkedIn, GitHub, Portfolio)
- Contact information

### Leave Requests
- **Apply for Leave** — Select dates, type (Sick/Personal/Emergency), add reason
- **Track Status** — View pending, approved, and rejected leave requests

### Notices
View warnings, notices, and announcements from the Training Coordinator. Acknowledge received notices.

### Hiring Cycles

### Hiring Demands

- View demand details and linked candidates

## Tips

- **Global Filter** (top bar) filters data by hiring cycle year across all pages
- **Dark/Light Theme** toggle is available in settings
- **Notifications** bell icon shows unread alerts
- **Profile menu** (avatar icon) provides logout and profile settings
- All tables support **sorting** by clicking column headers
- Large candidate lists are **paginated** — use page controls at the bottom
